# Biblioteca de testes em C

> [!INFO] Do que se trata o Projeto ?
> A ideia inicial e criar uma biblioteca para teste de funções e modulos em C, dessa forma garantido que bugs não se repitam ao ter a code base alterada ou conseguir rastrear os possíveis bug. Alem disso desevolvimento orientado a tests e uma otima forma de criação, manuteção e documentação do código.
